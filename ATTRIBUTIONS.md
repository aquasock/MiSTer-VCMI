# MiSTer-VCMI source attributions

This document records the provenance and licensing of third-party and reused
source that MiSTer-VCMI builds, patches, bundles or borrows from. It complements,
and does not replace, the copyright and license headers in individual files.

## Project code

The original code in this repository is distributed under the GNU General Public
License, version 2 or later, the same baseline as MiSTer-Raster and
MiSTer-Phosphor. It consists of:

- `scripts/` — the cross-build, bundling and deployment scripts and the CMake
  toolchain file.
- `sdl-driver/mister/` and `sdl-driver/mister-audio/` — the SDL2 video and audio
  drivers for the MiSTer, and the small test programs beside them
  (`sdl_test.c`, `sdl_bench.c`, `sdl_audiotest.c`, `membench.c`).
- `tools/` — the on-device test and profiling tools.
- The launcher (`run.sh`) and OSD script generated by `scripts/bundle.sh`.

Because the complete bundle also contains components licensed under GPL version 3
(FuzzyLite, below), distribution of the combined bundle should follow
GPL-3.0-or-later. The relevant full license texts are included as:

- `COPYING` — GNU GPL version 3
- `LICENSE.txt` — GNU GPL version 2, the baseline license for original project code
- `COPYING.ZLIB` — the zlib license as published by SDL (see "SDL", below)

`LICENSE.txt` and `COPYING` are the same texts used by MiSTer-Raster and
MiSTer-Phosphor. `LICENSE.txt` states the baseline license offered for original
project code; it does not override the terms carried by the third-party
components below.

### Relationship to MiSTer-Raster and MiSTer-Phosphor

MiSTer-Raster and MiSTer-Phosphor are FPGA cores. MiSTer-VCMI is ARM (HPS)
software and shares no source with them. They use the same licensing baseline, so
code owned by the projects could move between them under the shared
GPL-2.0-or-later terms.

## VCMI

The game engine is [VCMI](https://github.com/vcmi/vcmi), release 1.7.5 (commit
`6901839ae9760dfcd1d5ff2c4aa4ef6968fee752`), fetched by `scripts/build-vcmi.sh`
and not stored in this repository.

- VCMI source code is licensed GPL-2.0-or-later. VCMI project assets (the content
  installed under `data/Mods/vcmi` and `data/config` in the bundle) are licensed
  CC-BY-SA 4.0 by the VCMI project; see its `docs/Readme.md` and the
  [vcmi-assets](https://github.com/vcmi/vcmi-assets) repository for sources and
  contributors.
- The `Noto Sans` and `Noto Serif` fonts inside the VCMI mod are from the Noto
  project. The font files carry their own notice ("Copyright 2022 The Noto Project
  Authors ... licensed under the SIL Open Font License, Version 1.1"), and the
  release archive includes that notice and the license text as
  `LICENSES/Noto-OFL-1.1.txt`.
- **FuzzyLite** is a git submodule of VCMI (`AI/FuzzyLite`), statically linked into
  the Nullkiller AI library (`libNullkiller.so`). It is dual-licensed GPL-3.0 and
  proprietary; this project uses it under the GPL-3.0 terms, which is why the
  combined bundle follows GPL-3.0-or-later.
- The other VCMI submodules (googletest, innoextract, discord-presence,
  vcmi-dependencies) are fetched with the source but not built.

### Patches to VCMI

The files in `patches/` are modifications of VCMI and remain under VCMI's
GPL-2.0-or-later license. They are applied by `scripts/build-vcmi.sh`.

- `0001-spectator-skip-hero-town-list.patch` and
  `0002-spectator-no-player-color-index.patch` — fix two crashes in VCMI's
  spectator interface (undefined behavior with an empty player id).
- `0003-software-renderer-draw-into-texture.patch` — draws into the software
  renderer's texture memory, skips a redundant clear, makes the screen texture
  opaque, and holds the interface mutex while the screen is copied.

## SDL and its extension libraries

[SDL2](https://libsdl.org) 2.32.10, SDL2_image 2.8.12, SDL2_mixer 2.8.1 and
SDL2_ttf 2.24.0 are distributed under the zlib license. `COPYING.ZLIB` is SDL's own
license text and notice, reproduced unchanged; it applies to the SDL code below,
not to this project's original code.

- `sdl-driver/sdl2-mister-hooks.patch` and `sdl-driver/sdl2-resampler.patch` are
  modifications of SDL and remain under SDL's zlib license. The first registers the
  new drivers in SDL's driver lists and build files; the second replaces the
  per-frame divisions in SDL's audio resampler with an equivalent incremental
  integer form. Altered source versions must be plainly marked as such, and these
  patches are that marking.
- `sdl-driver/mister/` and `sdl-driver/mister-audio/` are new files written against
  SDL's internal driver interfaces and modelled on SDL's own `offscreen`, `kmsdrm`
  and `disk` drivers. They are offered under this project's GPL-2.0-or-later terms
  and are compatible with SDL's zlib license when built into the SDL library.

Codecs and loaders that SDL's libraries build in, and that end up in the bundle:

## Runtime shipped in the bundle

The MiSTer's root filesystem has an old glibc (2.31), so the bundle carries its own
runtime and starts the programs through its own dynamic loader (`patchelf` sets
the interpreter to `/media/fat/vcmi/libs/ld-linux-armhf.so.3`).

- **glibc 2.43** (Ubuntu) — `ld-linux-armhf.so.3`, `libc.so.6`, `libm.so.6`, and the
  charset conversion modules under `libs/gconv` (from Ubuntu's
  `libc6_2.43-2ubuntu2_armhf.deb`). License: LGPL-2.1-or-later. The programs link to
  it dynamically, so it can be replaced by the user.
- **libstdc++ and libgcc_s** (GCC 15.2, Ubuntu cross toolchain). License:
  GPL-3.0-or-later with the GCC Runtime Library Exception 3.1.

## MiSTer platform references

The framebuffer and audio drivers were written from reading the MiSTer sources.
No source was copied from them.

- [Main_MiSTer](https://github.com/MiSTer-devel/Main_MiSTer) (GPL-3.0) — the
  `fb_cmd*`, `video_mode` and `screenshot` commands on `/dev/MiSTer_cmd`, and how
  scripts and F9 switch the scaler to the Linux framebuffer.
- [Linux-Kernel_MiSTer](https://github.com/MiSTer-devel/Linux-Kernel_MiSTer)
  (GPL-2.0) — `drivers/video/fbdev/MiSTer_fb.c` and
  `sound/drivers/MiSTer-audio-spi.c`, which define the `/dev/fb0` frame reader and
  the `/dev/MrAudio` ring buffer.
- **MiSTer-Pet** — its notes on the framebuffer (`docs/mister-framebuffer.md`) were
  used as a reference. When `scripts/bundle.sh` finds `../MiSTer-Pet/src/fbterm_toggle.c`
  it compiles it into the bundle as `fbterm-toggle`, a test helper that sends a
  synthetic F9. That source is not stored here, and at the time of writing that
  project has no license file, so do not redistribute the `fbterm-toggle` binary
  until one is added. The launcher does not need it.

## Game data

Heroes of Might and Magic III data files are not included and are not licensed by
this project. You need your own copy (the GOG "Complete" release was used). They
are extracted with [innoextract](https://constexpr.org/innoextract/) and copied to
the device by `scripts/deploy.sh data`.

## Redistribution checklist

When publishing source or a bundle:

1. Include `COPYING`, `LICENSE.txt`, `COPYING.ZLIB` and this document with the
   corresponding source distribution. `scripts/release.sh` does this for the
   release zip and also adds each component's license text under `LICENSES/` and a
   `SOURCES.txt` with the exact source versions and checksums.
2. Preserve all per-file copyright and license headers in VCMI, SDL and the
   libraries above. The new driver files in `sdl-driver/` do not yet carry
   per-file license headers; add them before publishing.
3. Make the complete corresponding source available: this repository, the pinned
   upstream releases the scripts fetch (VCMI 1.7.5 and its submodules, SDL and its
   libraries, Boost, TBB and the rest), and the patches in `patches/` and
   `sdl-driver/`.
4. For a binary bundle, also ship the license texts of each bundled component
   (Apache-2.0 for oneTBB, the Boost license, the FreeType license, OFL for the Noto
   fonts, CC-BY-SA 4.0 attribution for VCMI assets) and make the glibc and GCC
   runtime sources available (Ubuntu source packages `glibc`, `cross-toolchain-base`
   and `gcc-15-cross`).
5. Do not include Heroes III data, and do not include `fbterm-toggle` (see above).

This inventory documents the repository as audited; it is not legal advice.
